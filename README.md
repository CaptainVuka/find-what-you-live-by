# find-what-you-live-by

> 我把建立人生方向的元方法,写成了一个 Claude Skill。

---

## 这是给谁的

- 处于人生的过渡期,面临重要选择的人
- 心里有想成为的理想自我,与现实之间有差距的人
- 想找到属于自己的原则,而不是接受别人清单的人

## 这套方法为什么管用

> 这套方法在我思索什么是重要的事情、以及面对挫折的时候,给过我巨大的力量。

### 1. 被验证过的方法论

富兰克林十八岁时经历了一系列挫折,狼狈不堪。1726 年,二十岁的他在回费城的船上写下了一份《行为计划》(Plan of Conduct)。这份手稿留下来了,是他人生第一份正式的自我管理文件。他写道:

> "我从来没有制定过任何正式的、有规律的生活计划,结果我的人生现在变成了一团乱麻、没有任何规划。从现在起,我决心定下一个我可以一直照着活的计划,以便从今往后我所有的行为都可以是一个理性的存在的行为。"

这个方法他用了一辈子。临终前承认有几条始终没做好,但他说:**"通过尝试,我成为了一个比我本来会成为的更好、更快乐的人。"**

### 2. 主体性为先

这个 Skill 不给你一份"100 条人生原则"清单。

读别人的清单当时很受启发,过两周就忘了——因为那不是你自己从生活里磨出来的。它帮你从**有重量的经历**里沉淀原则,用你自己认可的方式和语言。

### 3. 原则落地为可执行的行为

每条原则都被翻译成可观察的行为。

- **"节制"** 不是抽象品质,是「吃不到迟钝,喝不到亢奋」——两个具体的身体信号。
- **"勤勉"** 不是"努力工作",是「不浪费时间,始终做有用的事,切除不必要的行为」。

## 怎么用

### 安装

**Claude.ai / Claude Code(推荐)**
下载 [`find-what-you-live-by.skill`](./find-what-you-live-by.skill),在 Claude 客户端里直接导入。

**其他模型(ChatGPT、Gemini、Kimi、豆包、DeepSeek 等)**
打开 [`SKILL.md`](./SKILL.md),把全文复制到对话框作为 system prompt 或第一条消息。任何指令跟随能力够强的模型都能跑——但体验会有差别。这个 Skill 是在 Claude 上设计和测试的,其他模型在某些环节(比如保持镜子角色、不替你做决定)可能表现不同。

**从源码**
Clone 仓库,把 `SKILL.md` 放进 Claude 客户端的 skills 目录。

### 开始对话

找一个安静的 30–60 分钟,告诉模型:**"我想找到属于自己的原则"**——或者任何类似表达。

想先感受节奏,看一段示例对话:[examples/sample-conversation.md](./examples/sample-conversation.md)。

> ⚠️ 不适合急性心理危机、严重创伤、活跃精神疾病症状或失控成瘾——详见 [SAFETY.md](./SAFETY.md)。
